- Base de bots em discord.js

---

## 📦 Instalação

1. **Clone o repositório:**
```bash
git clone https://github.com/Iutkkj/base-discord.js.git
```


2. **Instale as dependências:**
```bash
npm install
```

---

## ⚙️ Uso

### 1. Registrar Slash Commands

Sempre que adicionar ou modificar a estrutura de um comando Slash, execute o script de deploy para atualizar os comandos no Discord:

```bash
node deploy.js

```

### 2. Iniciar o Bot

Para iniciar o bot em modo de produção:

```bash
npm start

```

*(Ou `node index.js`)*
